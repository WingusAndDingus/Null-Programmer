## 🕹️ Project Overview

In **Null Programmer**, the player assumes the role of a legendary senior C++ developer who wakes up with total amnesia. Over the course of one in-game week, the protagonist must complete a C++ Battleship project using SFML 3.0 via remote work while concealing their memory loss from an assigned junior developer named Steve. 

The game bridges the gap between basic C++ syntax and high-level software architecture, addressing common hurdles in early programming courses to help prevent student burnout in the CS major.

---

## ✨ Key Features

*   **Interactive Virtual Desktop:** Experience a simulated office environment featuring email, a code IDE, Zoom-like communication, an interactive UML architecture viewer, and coding minigames.
*   **Internal Personalities (Skill Levels):** Players allocate points into competing programming philosophies that guide their high-level technical choices:
    *   *The Grand Architect:* Obsessed with clean object-oriented programming (OOP) and design patterns.
    *   *The Pragmatist:* Favors fast solutions, global variables, and quick patches.
    *   *The Detective:* Focused on uncovering the mystery of the protagonist's past.
*   **Steve Suspicion System:** Players must manage Steve's suspicion to avoid getting exposed or fired.
*   **Branching Endings:** Multiple narrative conclusions driven by code quality, Steve's suspicion level, relationship paths, and personal connections.
